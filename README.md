## 项目名称：五子棋实时对战平台
## 技术栈：Spring Boot、WebSocket、MyBatis、HTML、Ajax、MySQL
## 核心功能：
1. 实现用户注册登录
2. 基于积分的天梯匹配机制
3. 通过websocket实现双人落子同步
4. 胜者+100，败者-100，同步更新积分、总场次、获胜场次
## 亮点：
- 设计WebSocket双向通信架构，实现大厅匹配与房间对战连接分离，支持多房间并发；
- 实现匹配队列+多线程唤醒机制，完成基于积分的分段匹配机制；
- 采用ConcurrentHashMap管理在线用户状态与房间映射，保证高并发下的线程安全；
- 采用Canvas绘制棋盘与棋子，实现流畅的落子交互与胜负判定（五子连珠算法）；
- 处理断线重连与异常场景：对手掉线自动判胜、重复登录拦截、房间资源释放；
